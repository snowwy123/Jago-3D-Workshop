# Jago 3D Workshop

Make a small scene and see where it takes you.

Shape objects and lettering, add artwork or a Material surface, and stage the result with light and a camera. Make a still, a short loop, a paper model or a projection study.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-3D-Workshop.exe**.

Try a study such as Prism or Kinetic Orbit. Change the light, move the camera and save the editable scene before exporting a render.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
