Welcome to your 3D workshop
Make dimensional artwork and little creative sets. Start with an example, then select an object to change its construction, material or placement.
Move / Rotate / Scale handles edit the selected object. Drag empty space to orbit, right-drag to pan and scroll to zoom. Front and Isometric get you back to a useful view.
Save project keeps artwork, construction, cameras and lighting together. The last completed edit is also autosaved locally; Recover autosave never replaces your set without asking.
SVG imports need simple filled paths and outlined lettering. Images become textured cards. Built-in lettering uses one bundled Latin typeface; use outlined SVG for your own fonts.
This is an independent experiment. Projection and printing are early workflows with explicit checks and limits. No cloud or account is used.
